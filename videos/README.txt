Add project demo videos to this folder using these filenames:

telemedicine-demo.mp4
data-analysis-demo.mp4
online-retail-analysis-demo.mp4
identification-system-demo.mp4
cyber-security-awareness-demo.mp4

The matching project expansion will show native playback controls when its MP4 is present.

To play the videos while testing locally, serve the portfolio over HTTP instead of opening index.html directly:

1. Open a terminal in the project folder.
2. Run: py -m http.server 8000
3. Open: http://localhost:8000
